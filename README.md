# 🛒 বাজার দর (BazarDor)

### নিত্যপ্রয়োজনীয় পণ্যের দাম এক নজরে

BazarDor is a web application designed to help users explore the daily prices of essential products in Bangladesh. Users can browse products by category, compare prices across different markets, and view price changes through a simple and user-friendly interface.

The application also provides user authentication and profile management features.

## ✨ Key Features

### 1. 📊 Daily Product Prices
- View the current prices of essential products.
- Explore product details and pricing information.
- Identify products with increasing or decreasing prices.

### 2. 🛍️ Product Categories
- Browse products by category.
- View products belonging to specific categories.
- Sort products to find the information more easily.

### 3. 📈 Market Price Comparison
- View minimum, maximum, and average prices.
- Compare prices across different markets.
- Explore market-wise prices for individual products.

### 4. 🔐 User Authentication
- Create an account using email and password.
- Sign in using Google or GitHub.
- Access protected pages after signing in.
- Sign out of the account.

### 5. 👤 Profile Management
- View account information.
- Update profile information.
- Access the profile page through the navigation menu.

## 🛠️ Technologies Used

- **Next.js 16** — React framework for building the application.
- **TypeScript** — Type-safe JavaScript development.
- **Tailwind CSS v4** — Responsive styling and layouts.
- **DaisyUI** — UI components and styling utilities.
- **Better Auth** — Authentication and session management.
- **MongoDB Atlas** — Database for user and authentication data.
- **React Hot Toast** — Notifications and user feedback.
- **External API** — Product and market price data.
